## Что там? — бесплатный бот с трендами

Что люди ищут в Google по вашей теме и почему? Бот собирает до пяти событий в одну сводку, показывает интерес к ним и даёт ссылки на источники.

1. Откройте бота в Telegram и нажмите **Start**.
2. Опишите, за чем хотите следить. Например, «Дринкит и рынок кофеен».
3. Выберите страны и время по Москве. Бот будет присылать сводку каждый день.
